2. Besuch unserer Website

Beim Aufruf unserer Website können technisch notwendige Informationen verarbeitet werden, beispielsweise IP-Adresse, Zeitpunkt des Zugriffs, Browsertyp und aufgerufene Seiten.

Diese Verarbeitung dient insbesondere der Bereitstellung, Sicherheit und Stabilität unserer Website.

Unsere Website wird über GitHub Pages bereitgestellt, einen Dienst von GitHub, Inc., USA. Dabei können technische Zugriffsdaten durch den Hosting-Anbieter verarbeitet werden. Eine Datenübermittlung ins Ausland ist möglich.

Weitere Informationen: Datenschutzhinweise von GitHub .

4. Google Analytics

Unsere Website verwendet Google Analytics 4, einen Webanalysedienst von Google. Damit können wir beispielsweise die Anzahl der Besucher, Seitenaufrufe, Nutzungsdauer und ungefähre geografische Herkunft auswerten.

Google Analytics wird auf unserer Website erst aktiviert, wenn Sie der Analyse ausdrücklich zugestimmt haben.

Dabei können insbesondere folgende Daten verarbeitet werden:

  • Seitenaufrufe und Nutzungsinteraktionen
  • Ungefähre geografische Herkunft
  • Browser- und Geräteinformationen
  • Technische Kennungen und Analyse-Cookies

Anbieter ist Google Ireland Limited, Irland. Eine Verarbeitung durch Google LLC in den USA oder eine Übermittlung in weitere Länder kann ebenfalls stattfinden.

Die Datenaufbewahrung richtet sich nach den Einstellungen unserer Google-Analytics-Property und den geltenden Aufbewahrungsregeln von Google.

Weitere Informationen: Datenschutzerklärung von Google .

5. Einwilligung und Widerruf

Beim ersten Besuch können Sie entscheiden, ob Sie Google Analytics zulassen möchten. Ihre Entscheidung wird lokal in Ihrem Browser gespeichert.

Sie können Ihre Entscheidung jederzeit über die Schaltfläche «Datenschutz» auf unserer Website ändern.

Bei einem Widerruf wird die weitere Analyse deaktiviert. Bereits übermittelte Daten werden dadurch nicht automatisch bei Google gelöscht.

6. Kontaktaufnahme

Wenn Sie uns per E-Mail kontaktieren, verarbeiten wir die von Ihnen übermittelten Angaben ausschliesslich zur Bearbeitung Ihrer Anfrage und zur damit verbundenen Kommunikation.
